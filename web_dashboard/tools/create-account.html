Créer un compte propriétaire

Cet outil génère du SQL prêt à coller dans le SQL Editor de Supabase pour créer un compte Super Admin qui existe uniquement dans le cloud (ni synchronisation avec l'app locale, ni création via l'app).

Aucun mot de passe n'est envoyé nulle part — tout se passe dans ce navigateur, hachage bcrypt inclus.

Doit être unique. Lettres, chiffres, sans espace.

Visible ici pour vérification. À communiquer à la propriétaire hors-ligne (message chiffré, papier, en main propre).

Choisi volontairement haut (≥ 9000) pour ne jamais entrer en collision avec les ids auto-incrémentés de l'app locale.

À coller dans Supabase → SQL Editor → Run
